# Reglas Estrictas del Proyecto Web-Educativa (Para Cline)

Como IA asistente en este proyecto, DEBES cumplir con las siguientes reglas sin excepción.

## 1. Reglas Técnicas de Código (Errores del Pasado)
- **PROHIBIDO usar Python, sed, awk o comandos de terminal para modificar archivos.** Usa EXCLUSIVAMENTE la herramienta de edición de archivos (Edit File / Write File).
- **NUNCA uses guiones bajos para Tailwind:** Las clases deben ser `px-4`, `py-2`, `bg-white`. NUNCA `px_4`, `py_2`, `bg_white`. Si usas guiones bajos, romperás el diseño.
- **No borres contenido sin preguntar:** Si se te pide modificar una sección, no borres el resto del archivo. Reemplaza solo el bloque indicado.
- **Nunca mientas sobre el Build:** Si el comando `npm run build` arroja un error, DEBES reportarlo textualmente y no decir "Build exitoso". No alucines éxito.
- **Revisa las rutas:** Asegúrate de estar editando el archivo correcto. Nunca manipules archivos con nombres raros (como `%5B%5D.sastro`).
- **Manejo de JSON:** Al modificar archivos JSON, asegúrate de respetar las comas, llaves y corchetes. Si un componente espera una propiedad (ej. `fragmento`), el JSON debe tenerla exactamente con ese nombre.
- **Trivias y Opciones:** Todas las preguntas deben tener IDs únicos (ej. `mq01`, `pe02`). Al generar opciones, mezcla el orden para que la respuesta correcta no sea siempre la B o la más larga.

## 2. Directrices Pedagógicas (MINEDUC)
- **Alineación obligatoria:** Todo contenido debe estar alineado con los Objetivos de Aprendizaje (OA) del MINEDUC (revisar `ALINEACION_MINEDUC.md`).
- **Progresión del aprendizaje:** El diseño debe seguir el enfoque Concreto → Pictórico → Simbólico. Si creas un componente, debe tener representación visual (conic-gradient, bloques, etc.).
- **No reinventar la rueda:** Si ya existe un componente funcional (como `SimuladorFracciones.astro` o `MetalofonoVirtual.astro`), reutilízalo o intégralo, no crees uno desde cero a menos que se solicite.

## 3. Privacidad y Ley de IA en Chile (Ley 21.719)
- **Protección de menores:** Los datos de las alumnas son categoría especial. Todo tracking (como los intentos fallidos) debe ser anónimo (usando `alumna_hash` y `mapa_identidad`).
- **Consentimiento:** Nunca expongas datos personales (PII) en el frontend sin consentimiento parental explícito (`consentimientos_tracking`).
- **Ley 21.719 (vigente desde Dic 2026):** La IA debe operar bajo los principios de transparencia, no discriminación y privacidad por diseño. Los informes individuales solo se generan bajo consentimiento específico.

## 4. Flujo de Trabajo Obligatorio
- Antes de modificar código, lee los archivos involucrados (`Read File`). No adivines.
- Si tienes dudas sobre un cambio, pregunta a la usuaria antes de aplicarlo.
- Al finalizar un bloque importante, recuerda a la usuaria hacer `git add .`, `git commit` y `git push`.
